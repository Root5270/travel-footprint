# 足迹手帐

一个可以旋转的 3D 地球旅行手帐：把想去的、去过的地方钉在地球上，给每个地点写手帐、存照片，去过的省份和国家会自动点亮。

- 拖动旋转地球，滚轮或双指缩放；放大后依次显示省、地级市、区县（含台湾县市和乡镇）。
- 数据只保存在你自己的浏览器里，别人看不到；用页面底部的“备份 / 恢复”可以在不同设备之间搬数据。
- 整个网站就是一个 `index.html`，不需要服务器。

数据来源：中国行政区划边界来自阿里云 DataV.GeoAtlas；台湾县市乡镇来自 taiwan-atlas（内政部国土测绘中心）；世界国界来自 Natural Earth（world-atlas）；地形来自 Mapzen Terrain Tiles（AWS 开放数据）。
